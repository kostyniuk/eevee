# Teaching notes

- Treat each implementation phase as one numbered lesson with one tangible skill.
- Use the artifact-style palette and editorial layout for every lesson and reference document.
- Keep each HTML artifact self-contained and offline-readable. This intentionally overrides the teaching skill's shared-stylesheet default.
- Do not create a learning record until the user completes the lesson's retrieval exercise in conversation.
- Preserve the explicit delivery constraint: no commit, merge, or pull request without user instruction.
